# 11 · Tropical Depression

Author: Alexander Walmsley · Started: 2026-11-02 · Status: sketch · Stack: static HTML + JS

What has to be measured, by whom, before a patch of cloud over warm sea is declared a tropical depression? This first page sets out the question, with a synthetic swirl as a placeholder.

## 1. Event

A tropical depression is the first stage of a storm that forecasters officially track and number: a low-pressure system over warm sea with a closed circulation and winds below 34 knots (about 63 km/h). Which storm, place and date this sketch follows is still to be chosen.

## 2. Simulate

For now, dots turn anticlockwise around one centre and drift slowly inwards, faster near the middle. It is synthetic and stands in for a real model or data.
