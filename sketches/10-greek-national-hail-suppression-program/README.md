# 10 · Greek National Hail Suppression Program

Author: Christos Montsenigos · Started: 2026-11-02 · Status: sketch · Stack: static HTML + JS

A first look at Greece's national hail suppression programme, which seeds summer storm clouds to try to stop hail. It asks: when the Greek state seeds these clouds, who decides which fields are protected?

## Run

Online, once published: `https://abj3ct.github.io/weather-commons/10-greek-national-hail-suppression-program/`

cd sketches/10-greek-national-hail-suppression-program
